# Docs

Operating and product documentation for this repository. The guides listed in `../developers.yml` are published to
[developers.dymini.com/panel](https://developers.dymini.com/panel) for every release.

| Path | Role |
| --- | --- |
| `HARNESS.md` | Human–agent collaboration model |
| `FEATURE_INTAKE.md` | Risk lanes before implementation |
| `ARCHITECTURE.md` | Layering and discovery rules |
| `CONTEXT_RULES.md` | What to read when |
| `TEST_MATRIX.md` | Behavior-to-proof map |
| `panel-https.md` | Warning and steps for a panel opened over plain HTTP |
| `mcp.md` | Connecting an AI agent and the permission templates |
| `build-hosts.md` | Installing trusted build hosts, placement, caching and troubleshooting |
| `plugins.md` | Installing and updating release-backed plugins, including Dockside |
| `domains.md` | Domain inventory, direct and Cloudflare routing, and DNS checks |
| `names.md` | Naming rules and understanding validation errors |
| `access.md` | Dymini Panel Access sign-in for internal apps |
| `security.md` | SSL, exposure checks, and shared rate limits |
| `i18n/<language>/` | Translations of the guides published to developers.dymini.com (`developers.yml` at the repository root) |
| `product/` | Product contracts |
| `stories/` | Story packets |
| `decisions/` | Architecture and product decisions |
| `templates/` | Reusable templates |
